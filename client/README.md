# DatasheetIQ client

This directory contains the React/Vite frontend for DatasheetIQ. It provides the upload and paste flows, extracted-parameter panel, hardware assistant chat, sample datasheets, and application shell.

For complete project documentation, local setup, API details, planned changes, and future projections, see the [root README](../README.md).

## Commands

```bash
npm install
npm run dev
npm run build
npm run lint
npm run preview
```

The frontend currently calls `http://localhost:3001/api`. Start the server in a separate terminal before using upload or chat features.
